# Moonlit Monarch OS — V6 PWA

## GitHub Pages

1. Create a GitHub repository.
2. Upload **all files and folders in this package** to the repository root.
3. Go to **Settings → Pages**.
4. Deploy from the `main` branch, `/ (root)`.
5. Open the HTTPS GitHub Pages URL on Android Chrome.
6. Choose **Install app** / **Add to Home screen**.

### App icon
This package uses the uploaded Moonlit Monarch logo as real PNG PWA icons:
- `icons/icon-192.png`
- `icons/icon-512.png`

The manifest is configured for standalone app installation.

### Important
Do not open `index.html` directly from your phone's file manager if you want the full PWA/offline installation behavior. Use the HTTPS GitHub Pages URL.
